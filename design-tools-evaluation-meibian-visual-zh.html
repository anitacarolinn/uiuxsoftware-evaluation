2026 新發展

Figma 現在也能 Prompt → Code 了

Figma 開放 MCP 之後，AI 可以直接在 Figma 裡生成設計 ＋ 出 code — 不再只是「畫設計稿」而已。

🐢 以前
美編在 Figma 畫設計稿 → 工程師手刻 code → 變成網站
→
⚡ 現在（用 MCP）
美編打字描述 → AI 直接在 Figma 生成設計 ＋ code
所以現在 Figma 跟 Paper 都做得到 — 兩個都有美編熟悉的 GUI 編輯器。
下一頁比比看，各自的強項 👉
MCP · 各自的強項

不一樣的地方 — 各取所長

兩個一起用，挑各自最好的 section 組合起來。

💎 Figma MCP
  • ✓ 新建 Design 檔 或 FigJam 白板
  • ✓ 讀既有 variables / 設計系統元件
  • ✓ 建新 variables / components
  • ✓ 自動畫架構圖（FigJam）
  • ✓ 把現有網頁抓進 Figma
  • ✓ 出多種 code（HTML / Tailwind / React）
適合：團隊已用 Figma + 設計系統
▶ 看 Figma MCP 範例檔 →
💎 Paper MCP
  • ✓ Prompt → 最漂亮的視覺（Paper 強項）
  • ✓ 原生 Tailwind code（單一 stack）
  • ✓ 從 Figma 匯入設計（插件）
  • ✗ 沒有 FigJam 類功能
  • ? 新建檔案 / 讀寫 variables、components 需驗證
適合：要高質感的單頁設計
▶ 看 Paper 範例檔 →
