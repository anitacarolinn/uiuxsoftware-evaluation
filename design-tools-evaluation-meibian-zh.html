AI 能幫美編什麼？

不是取代 Figma，也不用學寫程式 —— 把重複費時的工作交給 AI。

⚡
快速試很多版本
一句話生出一個畫面，不用每個風格都從頭畫。
🤝
工程師更快接手
Paper、Claude 這類工具直接出 code，工程師不用照著圖重刻，拿到就能用。
🎬
做出「會動」的原型
點按鈕會跳視窗、能換頁，比靜態圖真實。（主要是 Claude Design；Paper、Stitch 不會動）
🐢 傳統做法
Figma 畫出設計稿（圖） → 工程師照著圖重寫成 code → 才變網站
⚡ 用這些 AI 工具
出來本身就是 code → 工程師直接拿來用 → 快很多
關鍵：Figma 出「圖」，這些工具出「code」—— 工程師省下重刻的時間。

🖌️ Figma Design

美編現在用的（起點）

美編最熟悉的設計工具。先看它的強項與限制，再看 AI 工具能補什麼。
+ 強項
  • 🖱️ 完全用滑鼠操作 — 美編最順手，業界標準
  • 🎨 美感最可控 — 細節想怎麼排就怎麼排
  • 🗂️ 能同時放很多版本 — 多個畫板並排比較
  • 🤝 方便協作與交付 — 跟同事一起改、給工程師看
− 限制（AI 工具想補的）
  • 🤖 沒有「內建」AI — Figma Design 本身不會自己生成設計，要用 AI 得外接工具（詳見最後附錄）
  • 🖼️ 出的是「圖」不是 code — 還要工程師照著重刻成網站
  • 🎬 互動要一個個手動設定 — 原型做得出來，但每個點擊、跳轉都要自己慢慢接，很花時間
  • 🚀 不能直接變網站 — 要另外用 Figma Make，或交給工程師
🎯 重點：Figma Design 還是你畫設計的主力。下面的 AI 工具，是想幫你更快出版本、直接出 code、做出會動的成品。

下面 5 頁是每個工具的實測心得

🎨 Figma Make

實測心得

適合做一頁式的簡單小網站，一個按鈕就上線。
+ 優點
  • 🚀 一鍵上線 — 按一下就有網址可以分享，也能換成自己的網域
  • 🔗 是 Figma 自家的 — 跟你熟悉的 Figma 同一個帳號
  • 🛠️ 需要時工程師能接手 — 進階調整可以交給工程師
− 缺點
  • 🖱️ 不能用滑鼠改 — 只能打字下指令，美編會不習慣
  • 📱 不能切換手機/電腦預覽 — 要發布後才看得到
  • ↩️ 跟 Figma 設計檔不會雙向同步 — 這邊改了，Figma 那邊不會跟著變
🎯 結論：適合簡單的一頁網站，複雜的就不行。對美編來說「不能用滑鼠改」是最大的不便。

📐 Paper Design

實測心得

畫面最漂亮，而且能用滑鼠細修。很適合在意美感的美編。
+ 優點
  • ✨ 畫面最乾淨漂亮 — 出來就很專業，是我自己常用的工具
  • 🖱️ 能用滑鼠改細節 — 跟 Figma 一樣用點的、拉的，美編很好上手
  • 🤝 可以搭配 Claude 一起用 — 先讓 AI 生成，再進 Paper 細修
− 缺點
  • 🚫 只有畫面，不會動 — 按鈕點了沒反應
  • 🎬 不能模擬流程 — 沒辦法像 Figma 那樣串起來預覽
  • 💰 要另外付費 — 搭配 Claude 一個月大約 $36–40
🎯 結論：想要最漂亮的畫面 + 能用滑鼠細修，選它。缺點是做不出「會動」的互動。
看實際成品 →
⚡ Stitch AI

實測心得

免費、最快。最適合一開始快速試方向、做草稿。
+ 優點
  • 💸 免費 — Google 出的，每月有很多次額度
  • 🎨 能先設定風格 — 顏色、字型設一次，整份設計都套用
  • 📝 能直接點文字改字 — 這點對美編很方便
  • 📤 能匯出到很多地方 — 包括匯出到 Figma 繼續做
− 缺點
  • 🖱️ 版面只能打字改 — 改文字可以點，但整體排版要下指令
  • 🚫 幾乎不會動 — 點按鈕沒反應、不能換頁
  • 1️⃣ 一次只出一個版本 — 不能一次比較多種風格
🎯 結論：免費又快，做草稿、試方向最好用。但做不出真正的互動。
看實際成品 →
🚀 Google AI Studio

實測心得

能直接做出「能用」的完整網站，免費，還能上線。
+ 優點
  • 🎨 一開始有多種版面可選 — 還沒開始就先挑一個喜歡的
  • 🌐 做出整個能用的網站 — 不只是畫面，是真的能操作
  • 🖱️ 有限的滑鼠調整 — 顏色、字型、大小能點著改，但版面排版還是要靠 prompt
  • 💸 免費
− 缺點
  • 🎨 畫面比較陽春 — 能用，但不像專業設計工具那麼漂亮
  • ✨ 不適合很講究的視覺設計 — 它走「能用」優先
🎯 結論：想「快速做出能用的東西」最適合。但若很在意美感，畫面就略嫌陽春。

✨ Claude Design

實測心得

改法最多、互動真的會動。已經有 Claude 付費帳號就免費用。
+ 優點
  • ❓ 會先問你問題 — 確認觀眾、風格、功能才開始，結果更準
  • 🎬 互動真的會動 — 點按鈕真的會跳出視窗、會換頁
  • 🖱️ 改法最多 — 打字 + 滑鼠 + 直接畫 + 拉滑桿 + 留言
  • 💸 有 Claude 帳號就免費 — 不用另外再花錢
− 缺點
  • ⏳ 每週有使用額度 — 用太多要等下週
  • 🌐 只能用瀏覽器 — 沒有桌面版，沒網路就不能用
  • 🎯 結果看你怎麼回答問題 — 隨便答，結果就普通
🎯 結論：改法最多 + 真的會動，整體最全面。已有 Claude 帳號的話免費。

最實用的一頁

什麼情況，用哪個工具？

不用全部都學。看你當下要做什麼，挑對的工具就好。

⚡ 想快速試好幾個方向、做草稿
用 Stitch 或 AI Studio — 免費又快，先把點子看出來。
✨ 想要最漂亮的畫面 + 滑鼠細修
用 Paper — 美感最好，能像 Figma 一樣用滑鼠慢慢調。
🎬 想做「會動、點得下去」的原型
用 Claude Design — 點按鈕真的有反應，拿給人測試最真實。
🚀 想快速做個小網站直接上線
用 Figma Make 或 AI Studio — 一個按鈕就有網址能分享。
✅ 重點：Figma 還是你畫設計、跟同事協作的主力。這些 AI 工具是補在不同情境，不是要取代 Figma。
