🎨 Figma Make

Testing Notes

Generative design + 1-click deploy. Best for simple SPAs.
+ Strengths
  • 🚀 1-click publish — Figma hosts at .figma.site, or use custom domain
  • 🔌 GitHub + Supabase integrations — auto repo, connect DB
  • 📦 npm registry support — install framer-motion, recharts, etc.
  • ⚙️ Direct code edit — engineers can modify App.tsx directly
  • 🎯 Favicon, title, metadata editable in settings
− Weaknesses
  • 🖱️ No GUI canvas editing — prompts or code only, no drag-to-fine-tune
  • 📱 No responsive preview toggle — must prompt or check after deploy
  • ↩️ Export to Figma Design = one-way — edits don't sync back
🎯 Verdict: Great for simple SPA + quick deploy. Skip for complex apps. · Workflow: prompt → generate → deploy

📐 Paper Design

Testing Notes

Clean UI output + GUI editor. My go-to for projects.
+ Strengths
  • 🔗 Connect via Claude MCP — I generate via Claude, fine-tune in Paper
  • ✨ UI quality is clean — my project go-to, output looks polished
  • 🖱️ GUI editor for detail edits — 美編 can drag/click to fine-tune
  • ⚛️ Tailwind CSS native — utility classes ready to ship
− Weaknesses
  • 🚫 Pure UI only — no UX — click button = nothing happens
  • 🎬 No interactive preview — can't simulate flows like Figma's prototyping
  • 💰 Separate subscription — ~$36-40/mo total (Paper + Claude Pro)
🎯 Verdict: Best UI quality + GUI flexibility. Just no interactive UX. · Workflow: Claude (MCP) → generate → Paper GUI fine-tune → ship code
Open Paper project →
⚡ Stitch AI

Testing Notes

Free, fast, 8 export paths. The easiest first-draft generator.
+ Strengths
  • 💸 Free — Google Labs, 350 std + 200 pro generations/month
  • 📤 8 export options — AI Studio, Figma, Jules, .zip, code, MCP, brief, instant prototype link
  • 🎨 Design system tokens — set color theme + fonts once, applied everywhere
  • 📝 Direct text editing — click text in canvas to edit inline (only thing without prompt)
  • 📄 Pure HTML output — straightforward code, easy to use anywhere
− Weaknesses
  • 💬 Prompt-only editing — no GUI for layout changes
  • 🚫 Very limited interactions — only hover/active. Click button = nothing happens
  • 1️⃣ Single version per prompt — no multi-style variants in one shot
  • ❓ Future pricing unknown — currently free, may change
🎯 Verdict: Best first-draft tool. Don't expect interactive prototypes. · Workflow: prompt → generate → iterate → export anywhere
Open Stitch project →
🚀 Google AI Studio

Testing Notes

Build something that works. Full-stack, free, deployable.
+ Strengths
  • 🎨 Multi-style picker at start — choose layout/style before committing
  • 🌐 Full working website — generates complete-flow apps, not just static UI
  • 🖱️ GUI editor for color, font, size — visual tweaks without prompt
  • 🔁 Remix button — fork existing apps from gallery (like GitHub fork, 1-click)
  • 🔌 Integrations + Secrets — connect GitHub, API keys, Supabase
− Weaknesses
  • 🎨 UI quality less polished — functional, not "designer pretty"
  • ✨ Not for fine visual design — "make it work" > "make it beautiful"
  • 📚 No design system management — no reusable component library
🎯 Verdict: Best for "make it work fast." Skip for fine visual work. · Deploy: Cloud Run (1-click) OR .zip → Cloudflare/Vercel/Netlify
Open AI Studio project →
✨ Claude Design

Testing Notes

Most flexible editing + real interactions. Best if you're already on Claude Pro.
+ Strengths
  • ❓ Asks Q&A first — clarifies target audience, style, features before generating
  • 🎬 Real interactions baked in — click button → popup actually appears
  • 🛠️ 5 ways to edit — prompt + GUI + draw on canvas + tweak sliders + comments
  • 💬 Token separate from chat — heavy chat use ≠ design quota burned
  • 💸 No extra cost on Claude Pro — included in subscription
− Weaknesses
  • ⏳ Weekly quota limit — heavy use = wait for reset
  • 🌐 Browser-only — no offline mode, no desktop app
  • 🎯 Output depends on Q&A — lazy answers = mediocre output
🎯 Verdict: Most polished UX + flexibility. Free if already Claude Pro. · Workflow: prompt → Q&A → generate → tweak → preview → handoff
