下面 5 頁是每個工具的測試筆記

🎨 Figma Make

測試筆記

簡單網站一鍵發布。適合單頁網站。
+ 優點
  • 🚀 一鍵發布 — Figma 幫你放在 .figma.site，也能用自己的網域
  • 🔌 連 GitHub + Supabase — 自動建 repo，連資料庫
  • 📦 npm 套件 — 可以裝 framer-motion、recharts 等
  • ⚙️ 能直接改程式碼 — 工程師可以改 App.tsx
  • 🎯 圖示、標題、metadata 在設定就能改
− 缺點
  • 🖱️ 沒有滑鼠編輯介面 — 只能用指令或寫程式
  • 📱 沒有手機/平板/電腦預覽切換 — 要下指令或發布後看
  • ↩️ 匯出 Figma Design 是單向 — 改了不會同步回來
🎯 結論：適合做簡單單頁網站。複雜的不行。 · 流程：下指令 → 生成 → 發布
看實際網站 →  ·  看 Figma 專案 →
📐 Paper Design

測試筆記

畫面最漂亮，能改細節。我做專案常用的工具。
+ 優點
  • 🔗 用 Claude MCP 連接 — 用 Claude 生成，再進 Paper 細修
  • ✨ 畫面很乾淨 — 看起來很專業，是我的常用工具
  • 🖱️ 有滑鼠編輯介面 — 美編能直接改細節
  • ⚛️ 原生 Tailwind CSS — 程式碼可以直接用
− 缺點
  • 🚫 只有畫面，沒有 UX — 按鈕點了沒反應
  • 🎬 沒有互動預覽 — 不能像 Figma 那樣模擬流程
  • 💰 要另外付錢 — 加 Claude 一個月大概 $36-40
🎯 結論：畫面最漂亮 + 能細修。但沒有真的互動。 · 流程：Claude (MCP) → 生成 → Paper 細修 → 出程式碼
看 Paper 專案 →
⚡ Stitch AI

測試筆記

免費、最快、八種匯出。最適合做草稿。
+ 優點
  • 💸 免費 — Google Labs 出的，每月 350 + 200 次
  • 📤 八種匯出 — AI Studio、Figma、Jules、.zip、程式碼、MCP、簡報、預覽連結
  • 🎨 有設計樣式 — 設定一次顏色和字型，整個設計都用
  • 📝 可以直接改文字 — 點文字就能改（其他要用指令）
  • 📄 純 HTML 程式碼 — 簡單，到哪都能用
− 缺點
  • 💬 只能用指令編輯 — 沒有滑鼠介面改版面
  • 🚫 互動很少 — 點按鈕沒反應，沒有換頁、沒有彈窗
  • 1️⃣ 一次只出一個版本 — 不能一次做多個風格
  • ❓ 之後價錢不清楚 — 現在免費，未來可能改
🎯 結論：做草稿最好用。但不能做真的互動。 · 流程：下指令 → 生成 → 修改 → 匯出
看 Stitch 專案 →
🚀 Google AI Studio

測試筆記

直接做出能用的東西。完整網站、免費、能上線。
+ 優點
  • 🎨 一開始有多種風格可選 — 還沒做就先選版面
  • 🌐 做出整個能用的網站 — 不只是畫面
  • 🖱️ 有滑鼠介面 — 改顏色、字型、大小
  • 🔁 Remix 按鈕 — 一鍵複製別人的專案來改
  • 🔌 整合 + 密鑰 — 連 GitHub、API、Supabase
− 缺點
  • 🎨 畫面比較陽春 — 能用，但不像專業設計工具那麼漂亮
  • ✨ 不適合精細視覺設計 — 「能用」比「漂亮」重要
  • 📚 沒有設計系統 — 沒有可重複使用的元件庫
🎯 結論：「快速做出能用的東西」最好。精細視覺設計就不行。 · 上線：Cloud Run（一鍵）或下載 .zip → Cloudflare/Vercel/Netlify

✨ Claude Design

測試筆記

編輯方式最多 + 互動真的會動。已有 Claude Pro 就免費。
+ 優點
  • ❓ 會先問問題 — 確認觀眾、風格、功能再開始
  • 🎬 互動真的會動 — 點按鈕真的會跳出彈窗
  • 🛠️ 五種編輯方式 — 指令 + 滑鼠 + 畫圖 + 滑桿 + 留言
  • 💬 額度跟對話分開 — 一直聊天不會用掉設計額度
  • 💸 Claude Pro 不用多花錢 — 訂閱已經包含
− 缺點
  • ⏳ 每週有額度限制 — 用太多要等下週
  • 🌐 只能用瀏覽器 — 沒有桌面版，斷網就不能用
  • 🎯 結果看你怎麼回答問題 — 隨便答 = 結果普通
🎯 結論：編輯方式最多 + 真的會動。Claude Pro 用戶免費。 · 流程：指令 → 回答問題 → 生成 → 修改 → 預覽 → 交付

建議導入 Claude Design

★ 主要工具
導入 Claude Design 為慈濟數位
UI/UX 設計主要工具
✓ 優勢 STRENGTHS — 為什麼推薦
理由 01 · 成本
💰 已含在 Claude Pro 內
團隊已訂閱 Claude 付費帳號 — 零額外授權費，無需編列新預算。
理由 02 · 品質
🎨 設計符合需求
視覺乾淨、五種編輯方式（指令 + 滑鼠 + 畫圖 + 滑桿 + 留言），美編與工程師都能用。
理由 03 · 效率
⚡ Design → Code 最快
不用很多步驟，自動讀 codebase 用既有 components — 直接交付 Claude Code 上線。
理由 04 · 互動性
🎬 互動原型真的會動
Hover 有反應、點按鈕跳彈窗、頁面真的能切換 — 不只靜態畫面，能直接模擬用戶流程。Paper / Stitch 做不到。
⚠ 限制 WEAKNESSES — 需注意但可緩解
① 每週有額度限制
→ 大量設計時需排程使用
② 只有瀏覽器版
→ 斷網無法使用，需穩定網路
③ 編輯方式與 Figma / Paper 不同
→ 美編習慣傳統工具者需 1-2 週適應期
④ 無法同時看多個版本
→ Figma / Paper 可同時開多畫板對比 V1 / V2 / V3，Claude Design 每次迭代覆蓋前版 — 需手動截圖或開瀏覽器分頁才能比較不同設計方案
